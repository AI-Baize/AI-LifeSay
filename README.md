# AI LifeSay

AI LifeSay 是 AI白泽以个人方式筹备的家庭生活英语学习应用。首期面向 3–6 岁儿童和家长，把日常对话放进起床、穿衣、餐前、睡前和户外等具体场景。0–22 岁是长期衔接规划。

0.95 首发范围为免费 30 个场景。课程随 Android 安装包提供，免费学习无需购买或申请设备许可。后续新增分级资源将根据验收结果单独提供。

- **首页和学习**可找场景、看图学句子、点读和查看单词卡。
- **听一听**可选择多个场景，按课程顺序循环播放，并显示正在播放第几个场景。
- 家长可陪孩子听、说和读。完成活动只记录使用过程，不作为英语能力测评结果。

安装、更新及家长使用方式见 [使用指南](INSTALL.md)。权利和隐私说明见 [权利说明](RIGHTS.md) 与 [隐私说明](PRIVACY.md)。联系 AI白泽请使用 aibaize@yeah.net。

当前材料用于本地上线验收，发行状态以经过核准的下载页面为准。
