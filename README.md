# AI LifeSay

给家庭使用的生活英语分级学习工具。

我是AI白泽，AI LifeSay的独立开发者。这个项目内部叫AiEnglish，整体面向 **0–22岁学习者及其家庭**，目前内容资源主要集中在 **3–6岁**。

我想解决的问题很具体：家长有了绘本、动画和音频，仍可能不知道怎样和孩子一起用。AI LifeSay把生活场景、英文对话和成人引导交流放在一起，帮助家庭开始一次活动，也为生活中下一次使用留下线索。

## 它可以怎样用

玩具打不开时，家长可以先看一次求助表达的示范，再在自然的生活机会里陪孩子尝试。一起玩轮流游戏，可以练习简单的来回；一起看故事，可以听一段、找线索、聊一聊。

孩子可以先听、看、指认，愿意时再尝试表达。需要帮助时，成人先提供帮助，不把说英语作为得到照护的条件。

活动按内容提供带着做、跟读、点读或自己读等方式。图片是主要展示内容，英文对话可以逐句重听；家长说明折叠呈现，活动可以暂停和结束。跟读不要求录音评分，学习记录可选。

这些是产品的使用方式，具体哪些活动与资源可以取得，以对应版本清单为准。

项目内部所说的“专家方法蒸馏”，就是把上述公开方法整理进AI研发角色与检查流程。它不是专家数字分身，也不是对这些专家进行了模型训练。

研发时会检查目标、台词、图像、声音和使用条件之间的关系。例如，成人先示范了一句，后面的模仿就不能写成独立表达；台词改了，对应声音和图像也需要复核。AI能帮助发现问题，但不替代独立教学审阅、语言审校、声音审听和真实家庭使用验证。目前这些工作仍逐项推进。

## 英语怎样分级

年龄、语言准备度和活动支持分别判断。同样5岁的孩子可以从不同位置开始；年长的英语初学者，也需要符合其生活经验的题材。

| 维度 | 看什么 |
|---|---|
| 年龄与兴趣 | 题材、人物、知识和操作方式是否合适 |
| 生活听说 | 要理解什么、表达什么，交流有几轮，需要多少提示 |
| 阅读材料 | 词义、句法、篇幅、结构、图像依赖和理解任务 |
| 音形与解码 | 已教字母—声音对应、例外词和词义是否足以支持读这份文字 |
| 支持条件 | 成人示范、提示、共同完成或独立尝试 |

规划中，生活听说有8个大级、32个小级；阅读材料另有29个编辑小级。音形学习按确切先修组织，不按读完几包自动升级。分级体系已作规划，正式内容仍需按版本逐步审定和交付。

我们参考RAZ的阅读材料梯度、Oxford Reading Tree的故事与阅读支线，以及CEFR语言活动描述和相关阅读研究，使用项目自己的课程标签，不作官方等值换算。

孩子听懂故事、跟着朗读、看图猜到意思与自己读出新词，分别看待。点读、翻页和活动结束也不会自动生成能力成绩。

## 为什么选择这样的产品形式

**家长有具体的带领提示。** 除了图片和声音，还能看到这次准备做什么，以及孩子需要支持时可以怎么带。

**活动能联系到日常。** 练习中的表达有生活用途，家长可以在下次自然机会里再试，不必每次都学新内容。

**听说与阅读分别发展。** 可以先听丰富的故事，同时从适合的音形和文字材料开始识读，不要求两条线同步升级。

**跟读不录音评分，记录可选。** 产品以本机使用和本机学习记录为中心，不提供真人教师服务或实时AI外教。

**已安装内容按许可离线使用。** 下载、购买联系、更新与恢复可能需要网络。系统清理、卸载或换机可能影响文件，离线不等于不需要备份。

这些是产品取向。大型读物库、综合英语课程和其他学习工具各有适用场景，目前没有本项目教育效果优于它们的验证结论。
